<objective>
Add per-run failure detection and post-run reporting to `scripts/sweep.sh` using the xargs-safe
per-file marker pattern. `run_one` writes a `.attempted` marker after every run and a `.failed`
marker when a run produced neither `metrics.json` nor any `output/` file (a hard crash, D-01).
`main()` cleans stale markers before the sweep, prints a `summary:` line tallied from `.attempted`
markers + each run's `benchmark_status` (SWP-03), and exits non-zero with each failed run's log
path on stderr when any `.failed` marker exists (SWP-04).

Purpose: Give CI an actionable exit code and a one-line pass-rate summary without re-scanning the
results tree. Distinguish hard crashes (runner died, no artifacts) from operational outcomes
(timeout/agent_error still write metrics.json).

Output: Modified `scripts/sweep.sh` with marker writes in `run_one`, a `tally_summary()` and
`check_failures()` function, marker cleanup, and the new call sites wired into `main()`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parallel xargs workers → $LOG_DIR | Each worker writes its own per-run marker; no shared mutable file |
| metrics.json on disk → tally_summary | Untrusted-ish JSON parsed by grep for benchmark_status |
| sweep.sh exit code → CI consumer | CI acts on the non-zero exit and stderr log paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Tampering | concurrent marker writes under xargs -P | mitigate | Per-file markers keyed by deterministic run_id (no shared file); `touch` is atomic per path; no append contention (research Anti-Pattern: avoid shared-file append) |
| T-07-05 | Denial of Service | stale markers from prior pass inflate summary | mitigate | `main()` runs `rm -f "$LOG_DIR"/*.attempted "$LOG_DIR"/*.failed` before xargs (D-04) |
| T-07-06 | Spoofing | malformed benchmark_status in metrics.json | mitigate | `case` defaults any unrecognized status to missing_deliverable bucket; no eval of file contents |
| T-07-07 | Repudiation | silent crash with non-zero exit but no pointer | mitigate | check_failures prints each failed run's log path to stderr before exit 1 |
</threat_model>

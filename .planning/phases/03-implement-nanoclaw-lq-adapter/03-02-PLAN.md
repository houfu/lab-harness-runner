<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python adapter → Node shim (subprocess) | adapter passes group_id, message-id, and message content as process arguments |
| adapter → nanoclaw container_configs DB | adapter writes Docker bind-mount sources (additional_mounts) consumed by `docker run` |
| caller → nanoclaw daemon | message content is delivered into a container that executes an agent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Tampering | additional_mounts hostPath values | mitigate | Only `task_spec.documents_dir` and `output_dir` are written as hostPaths; no caller-controlled arbitrary path reaches additional_mounts; nanoclaw's `validateMount()` + mount-allowlist is the second gate |
| T-03-05 | Elevation of Privilege | subprocess invocation of the Node shim | mitigate | Explicit list-form `subprocess.run([...])`, never `shell=True`; group_id pre-validated by `_reject_unsafe_relative_path`; msg_id is a server-generated uuid4 |
| T-03-06 | Tampering | containerPath in additional_mounts | mitigate | Use relative names "lab-documents"/"lab-output" (Pitfall 3); nanoclaw rejects absolute/`..` containerPaths |
| T-03-07 | Denial of Service | sqlite3 write to container_configs / read of outbound.db | mitigate | open/operate/close per op; mounts configured before wake; poll never holds a connection across sleep |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No new Python packages (stdlib only). The Node shim adds NO new nanoclaw-lq dependency — it imports existing session-manager/container-runner modules and runs under the repo's existing pnpm/tsx; RESEARCH Package Legitimacy Audit confirms zero installs |
</threat_model>

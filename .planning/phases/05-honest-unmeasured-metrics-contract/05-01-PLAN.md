<objective>
Make `RunResult` distinguish "adapter measured 0" from "adapter did not measure" by changing the list-field defaults to `None` and removing the `None → 0` / `None → []` coercions in `write_metrics`. The output on disk is JSON `null` for unmeasured fields, preserving the underlying value unchanged for measured ones.

Purpose: This is the core of CON-01 (distinguishable measured 0 vs unmeasured) and the on-disk half of CON-02 (unmeasured fields write `null`).

Output: Three files updated — `adapter.py` (field default change), `metrics.py` (no coercion in `write_metrics`), `tests/test_metrics.py` (replaced and added tests).
</objective>

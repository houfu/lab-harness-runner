**Module-level imports** (in this order):

**Routing predicate** (D-10):
- Define `def is_claude_model(model: str | None) -> bool` — returns `True` iff `model` is a non-empty string and starts with the case-sensitive prefix `"claude"`. Body: `return bool(model) and model.startswith("claude")`. Do NOT introduce any other "is X model" helper.

**Protocol** (D-01):
- Define `class MetricsExtractor(Protocol)` with one method:
  `def extract(self, messages_out: list[dict]) -> RunResult: ...`
- The protocol carries no other surface; `messages_out` is kept on the signature for protocol uniformity (a future Ollama-aware extractor that reads from `messages_out` can still implement it), even though the Anthropic path ignores it and reads the transcript directly per D-03.

**Private transcript-reader base** (DRY for the two Anthropic extractors):
- Define a small private class `_TranscriptReader` with `__init__(self, transcript_dir: Path, session_id: str)`, `_resolve_transcript(self) -> Path | None`, and `_iter_jsonl(self, path: Path)` generator. The resolver and iterator are the shared substrate; both `AnthropicUsageExtractor` and `DocumentReadExtractor` inherit from it. This keeps the resolver in one place (D-04) while leaving the public classes distinct (D-09: the combined class is a thin compose, not a deep inheritance).
- `_resolve_transcript`: list `*.jsonl` entries in `self.transcript_dir`; for each, open it and parse lines until a line's parsed `sessionId` field matches `self.session_id`; return that jsonl path. If the dir does not exist, return `None`. If no jsonl matches, return `None`. NEVER raise — wrap the JSON parse in `try/except (json.JSONDecodeError, OSError)` and skip non-matching / unparseable files. Defensive against prior-run jsonls (the v1.0 proof group `820628bb-...` may share a group dir; D-04 anchored this case). The schema question of "where does `sessionId` live in a real nanoclaw transcript" is a Plan 03 live-run concern; for the synthetic fixtures the test helper places `sessionId` on the first line, which is the most permissive reading.
- `_iter_jsonl(path)`: yield each successfully-parsed line dict; skip `json.JSONDecodeError` and `OSError` per line, do not raise. (D-06: malformed lines are skipped, not raised.)

**AnthropicUsageExtractor** (D-03..D-06, D-09):
- `class AnthropicUsageExtractor(_TranscriptReader):` — inherits the constructor and helpers.
- Public method `extract(self, messages_out: list[dict]) -> RunResult`:
  1. Resolve the transcript via `self._resolve_transcript()`. If `None`, return `RunResult(run_id="", end_state="clean", wall_clock_seconds=0.0)` — every token / coverage field is left at its `None` default. The `run_id=""` is the extractor telling the adapter "I have nothing to say"; the adapter overwrites it with the real `run_id` from `task_spec` (D-13 step 2 in Plan 02).
  2. Otherwise, stream the jsonl via `self._iter_jsonl()`. For every line whose `line.get("type") == "assistant"` AND whose `line["message"].get("usage")` is a dict, accumulate the per-line values into running totals:
     - `input_total += usage.get("input_tokens", 0) + usage.get("cache_creation_input_tokens", 0) + usage.get("cache_read_input_tokens", 0)` (D-05 cache fold; both cache fields are folded).
     - `output_total += usage.get("output_tokens", 0)`.
  3. If at least one assistant usage block was summed, return `RunResult(run_id="", end_state="clean", wall_clock_seconds=0.0, input_tokens=input_total, output_tokens=output_total)`. The remaining fields stay `None`. If NO assistant usage block was found (e.g. the jsonl is empty or all lines are non-assistant), return the same `RunResult` with all token / coverage fields `None` — same as the "missing transcript" path. This is the D-04 / D-06 "no schema" shape.
  4. Do NOT add cache fields as sidecars. RunResult's surface stays unchanged. The fold is documented in `docs/adapter-guide.md` (Plan 03, D-20).

**DocumentReadExtractor** (D-07, D-08, D-09):
- `class DocumentReadExtractor(_TranscriptReader):` — same constructor.
- Public method `extract(self, messages_out: list[dict]) -> RunResult`:
  1. Resolve the transcript. If `None`, return the no-schema `RunResult` (same shape as `AnthropicUsageExtractor`).
  2. Stream the jsonl. For every line whose `type == "assistant"` AND whose `line["message"].get("content")` is a list, iterate the content blocks. For every block where `isinstance(block, dict) and block.get("type") == "tool_use" and block.get("name") == "Read"`, read `block.get("input", {}).get("file_path")` and append to a list, deduplicating with order preserved (first occurrence wins — D-07). Use a `seen: set[str]` + list pattern; the order in the list is the order in the transcript. Skip blocks with no `file_path` or non-string `file_path` (defensive: read the value via `if isinstance(fp, str)`).
  3. If at least one `Read` block was collected, return `RunResult(run_id="", end_state="clean", wall_clock_seconds=0.0, documents_read=len(read_list), documents_read_list=read_list)`. The remaining fields (including `documents_skipped` and `documents_skipped_list`) stay `None` (D-07 — no skip signal in the transcript).
  4. If zero `Read` blocks were collected, return the same `RunResult` with `documents_read=None` AND `documents_read_list=None` — same null shape as the "missing transcript" path. This is the "no document reads observed" signal.
  5. Do NOT touch the `file_path` strings (D-08 — verbatim container paths).

**AnthropicTranscriptExtractor** (D-09):
- `class AnthropicTranscriptExtractor:` with `__init__(self, transcript_dir: Path, session_id: str)`. Construct an `AnthropicUsageExtractor(self.transcript_dir, self.session_id)` and a `DocumentReadExtractor(self.transcript_dir, self.session_id)` on the instance as `self._usage` and `self._docs`. This is the thin compose (per Claude's Discretion: a class is one acceptable shape).
- Public method `extract(self, messages_out: list[dict]) -> RunResult`:
  1. Call `self._usage.extract(messages_out)` and `self._docs.extract(messages_out)`.
  2. Build a merged `RunResult` from the two return values field-by-field. The merge rule: take any non-`None` value from either return; the result's `end_state="clean"` and `run_id=""` (adapter fills it in). Use the following copy pattern explicitly:
     - `merged = RunResult(run_id=usage_result.run_id or docs_result.run_id, end_state="clean", wall_clock_seconds=0.0)` (both parents use `run_id=""`, so the result is `""` — the adapter overwrites it).
     - For each LAB metric field in `(input_tokens, output_tokens, documents_read, documents_skipped, total_vdr_files, documents_read_list, documents_skipped_list)`: set `merged.<field> = usage_result.<field> if usage_result.<field> is not None else docs_result.<field>`. (Usage owns `input_tokens` / `output_tokens`; docs own `documents_read` / `documents_read_list`; both are `None` for the others — the merge is "first non-None wins", which degenerates to "either value is the value" because the two extractors fill disjoint fields.)
  3. Return the merged `RunResult`.

**NoOpExtractor** (D-10):
- `class NoOpExtractor:` with no `__init__` args (the no-op does not need a path; the routing decision is made before the class is constructed). Optional `__init__(self, *args, **kwargs)` that accepts and ignores any args is acceptable for protocol uniformity.
- Public method `extract(self, messages_out: list[dict]) -> RunResult`:
  1. Return `RunResult(run_id="", end_state="clean", wall_clock_seconds=0.0)` — every token / coverage field left at `None`.
  2. Do NOT read `messages_out` (it is part of the signature for protocol uniformity only; the no-op ignores it).
  3. Do NOT raise under any input.

- Any change to `scripts/run_benchmark.py`.

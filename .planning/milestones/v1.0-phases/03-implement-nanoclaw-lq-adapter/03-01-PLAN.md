<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → NanoclawAdapter constructor | group_id is caller-supplied and later used to locate session DB paths under nanoclaw's data dir |
| nanoclaw container (writer) → adapter (reader) of outbound.db | adapter reads a SQLite file written by an external Docker container |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | group_id used in DB path construction | mitigate | Call `_reject_unsafe_relative_path(group_id, "group_id")` in `__init__` — rejects absolute paths and `..`/`.`/empty segments before any path is built |
| T-03-02 | Denial of Service | persistent sqlite3 connection on a virtiofs cross-mount | mitigate | Open/read/close per poll iteration; never hold a connection across `time.sleep` (one-writer invariant, RESEARCH Pattern 2) |
| T-03-03 | Information Disclosure | malformed/non-JSON content in messages_out | accept | `json.loads` wrapped in try/except with raw-text fallback; no crash, no leak — content originates from the same-machine container, low value |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan (stdlib only); RESEARCH Package Legitimacy Audit confirms zero new packages |
</threat_model>
